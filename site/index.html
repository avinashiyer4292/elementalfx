ELEMENTALFX

Water, air, fire and earth for the web. Five small effect packages that work with plain HTML, any framework, or a script tag.

npm install @elementalfx/weather

The snow is the weather package, settling on the letters. Move the pointer to push the wind.

Your system asks for reduced motion, so the effects stay still. Turn that setting off to see them move.

Ripples

Water ripples on any image, video or CSS background, rendered with WebGL.

Click or drag across the water.

@elementalfx/ripples, about 10 KB gzipped

Dissolve

        
Make any element crumble into dust, burn away, melt or fade, then bring it back the same way. The real element stays on the page the whole time; an SVG filter hides it piece by piece.

      

      

        
        
        
        
      

      

        

          
Click a card. It comes back on its own a moment later.

          
@elementalfx/dissolve, about 7 KB gzipped

        

        

      

    


    

      

        
React

        
Components and hooks for every effect. They render on the server, start after mount, and update the running effect when options change.

      

      

        

          
Install the React package with the effects you use. Each effect has its own entry point.

          

            npm install @elementalfx/react @elementalfx/dissolve
            
          

        

        

      

    

  


  

    
Every effect respects reduced motion, stops drawing when nothing is happening, and cleans up after itself.
